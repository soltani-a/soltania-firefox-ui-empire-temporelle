# Sécurité

## Périmètre

Empire temporelle est un thème statique Firefox. Le paquet contient un manifeste et une image SVG locale. Il n’exécute aucun JavaScript et ne demande aucune permission de navigation.

La branche `main` est la référence pour les corrections. Aucun délai de réponse ou de correction n’est garanti.

## Signaler un problème

Ne publiez pas de secret ni de détail d’exploitation sensible dans une issue publique. Utilisez le signalement privé de vulnérabilité GitHub s’il est disponible dans l’onglet **Security**. Sinon, ouvrez une issue indiquant uniquement qu’un canal privé est nécessaire, sans détails sensibles.

Pour les problèmes de couleurs, de lisibilité ou de mise en page, utilisez une issue classique.

## Distribution

Le ZIP construit sur GitHub est non signé. Une installation durable dans Firefox standard nécessite la signature Mozilla. Ne désactivez pas les protections du navigateur pour l’installer.
